# CS362 — Software System and Design

Interactive teaching website for CS362, Computer Science, Thammasat University.

## Features
- 9 complete lectures (L1–L9)
- Quick reference cheat sheet
- Search by topic
- Mobile responsive
- Dark theme, zero dependencies

## Lessons
| Lecture | Topic |
|---------|-------|
| L1 | Software Architecture Introduction (SDLC, Architectural Thinking) |
| L2 | Requirements & User Stories (Functional vs NFR) |
| L3 | UML & System Modeling (Use Case, Class, Sequence) |
| L4 | Architecture Styles + SOLID Principles |
| L5 | Design Patterns (Singleton, Factory, Observer, Strategy) |
| L6 | Design Mapping & Implementation Planning |
| L7 | Git Workflow & Conventional Commits |
| L8 | Large System Design (DDD, Caching, Database Strategies) |
| L9 | Architecture Testing (Load, Stress, Security) |

## Usage

### Local
Open `index.html` directly in any browser — no server needed.

### GitHub Pages
1. Push to GitHub
2. Settings → Pages → Branch: main → Save
3. Access at `https://<username>.github.io/<repo-name>/`

### Netlify / Vercel
Drop the folder into Netlify Drop or connect the GitHub repo — deploys automatically.
